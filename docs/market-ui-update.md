# Market menu and table placement update

Collected puddle coupons are associated with stable restaurant IDs. The matching
restaurant menu shows a Coupon available button that opens the saved offer. These
remain game collectibles, not verified real-world restaurant discounts.

Menu and game focus rings share a 1.5px rounded orange glow. Dish portion buttons
enter immersive AR directly when the browser reports support, otherwise retain
the screen preview. Surface placement accepts native hand select events as well
as controller triggers. Spectacles retains fingertip table calibration because
its browser hit testing is emulated. Existing 3D and 2.5D scale rules are unchanged;
unmeasured dishes remain explicitly estimated from a 27cm plate reference.

Device table alignment and passthrough still require headset validation. Desktop
unit checks cannot establish physical accuracy.

Ingredient artwork now renders in a centered 56px slot (previously 38px), above
centered one/two-line ingredient names. Restaurant headers and comparison labels
use the original JerseyTitle pixel face. User-provided prices are $21.00 for the
fried chicken bowl and $19.00 for the steak ramen; dish/save IDs are unchanged.
Portion screens (desktop and immersive AR) show the menu serving count or the
user-authorized fallback “Estimated serving for 1 person” when absent.
